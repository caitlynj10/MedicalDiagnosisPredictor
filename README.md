# Medical Diagnosis Prediction Algorithm 
This project was created during a class, _Numerical Methods and Big Data_, and contains Python scripts for multi-class medical diagnosis prediction (e.g., distinguishing between FLU, COLD, and ALLERGY based on patient symptoms) using distance-based clustering, rule-based heuristics, and linear regression. The primary pipeline trains single-cluster KMeans models (k=1) on symptom features to establish representative centroids for each condition, assigns test instances to the nearest centroid using Euclidean distance, and refines predictions through domain-specific rules (such as reclassifying ALLERGY to FLU when a FEVER feature is present). Additionally, it includes a Ridge regression baseline and evaluates model performance through overall accuracy scores, per-diagnosis breakdown metrics, and scatter-plot visualisations of class centroids.
